## Getting Started

This project uses Node.js 24 and npm 11. With NVM installed, select the pinned
runtime and install the locked dependencies:

```bash
nvm use
npm ci
npm run dev
```

`package-lock.json` is authoritative. Use npm for dependency changes and do not
commit lockfiles generated by other package managers.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Supabase Setup

1. Create a Supabase project from the Supabase dashboard.
2. Copy `.env.example` to `.env.local`.
3. In the Supabase dashboard, open Project Settings, then API, and copy the Project URL and publishable key into `.env.local`:

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

4. Log in to the Supabase CLI:

```bash
supabase login
```

5. Link this repository to the hosted project:

```bash
supabase link --project-ref your-project-ref
```

6. Apply migrations to the linked project:

```bash
supabase db push
```

7. Run seed data. For local development this is included by reset:

```bash
supabase db reset
```

For a fresh linked dev or staging project, you can include seed data when pushing migrations:

```bash
supabase db push --include-seed
```

Do not use seed pushes against production data without reviewing the SQL first.

8. Generate TypeScript database types after linking:

```bash
npm run db:types
```

9. Run the Next.js app:

```bash
npm run dev
```

## Skatepedia catalog import

The hosted media lives in the public Supabase Storage bucket `trick-media` under
`clips/`, `posters/`, and `controls/`. Database rows store bucket-relative paths,
so the dataset is not tied to one Supabase project URL.

Regenerate the deterministic seed from the final Skatepedia export:

```bash
npm run db:seed:generate -- path/to/skatepedia.json
```

The generator validates unique slugs and required media references before
replacing `supabase/seed.sql`. Applying the rebuild migration drops and recreates
only `trick_categories`, `tricks`, and `trick_metrics`; it does not alter Auth or
Storage.
